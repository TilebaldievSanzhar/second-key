# ADR 0002 — Стек

Статус: принято · 15.10.2026

| Слой | Выбор | Почему |
|---|---|---|
| Язык бэкенда | Python 3.13 | движок, OCR и LLM-слой уже на Python; 3.13 — зрелые колёса всех зависимостей |
| Зависимости | uv + `uv.lock` | воспроизводимые сборки, быстрые образы |
| API | FastAPI + Pydantic v2 | async, OpenAPI для генерации клиента фронта |
| БД | PostgreSQL 17 (образ pgvector) | транзакции для денег, JSONB для доказательств, pgvector для будущего поиска по номенклатуре |
| ORM и миграции | SQLAlchemy 2 (async, asyncpg) + Alembic | типизированные модели, миграции в репозитории |
| Очередь | taskiq + Redis (ADR 0003) | async-воркеры, расписание, совместимость с FastAPI |
| Файлы | S3-совместимое хранилище: MinIO локально, любой S3 в проде | выгрузки клиентов не лежат на диске API |
| Прогресс задач | Redis pub/sub → Server-Sent Events | простой однонаправленный поток, работает через nginx |
| Аутентификация | email + пароль (argon2), JWT в httpOnly-cookie, роли в организации | B2B, вход по приглашению; токен недоступен JS |
| Логи | structlog, JSON в проде, request_id | разбор инцидентов по одной строке |
| Качество | ruff (линт и формат), pytest, pytest-asyncio | один инструмент для стиля |
| Фронт | React 19 + TypeScript + Vite, React Router, TanStack Query, TanStack Table | SPA за авторизацией не требует SSR; таблицы доказательств — основной UI |
| Деплой | Docker multi-stage, non-root, healthcheck; compose для dev и single-host prod | одна команда до работающего стека |

Числа денег — `Numeric(18, 2)` в БД и `Decimal` в коде; float запрещён в денежной логике.

Мультиарендность — колонка `org_id` во всех предметных таблицах и обязательный фильтр в
сервисном слое (зависимость `CurrentMember`). Row-level security в Postgres — следующий шаг при
выходе за пределы одного инстанса.
