## Текст для вставки в Claude Design

Продолжаем «Второй ключ». Проход 1 реализован в коде; дизайн-систему (токены, KeyPair, FindingRow, MoneyAmount,
Golos Text + IBM Plex Mono, радиусы 2/6) не меняй — дополняй. Нужен проход 2:

1. **Состояния всех экранов** — пусто, загрузка (скелет), ошибка с повтором, офлайн, «длинные» данные
   (поставщик в 80 символов, 200 вопросов, сумма 1 234 567 890 сом) для: сводки, входящих, карточки вопроса,
   «Мои вопросы» снабженца, загрузки (файл, колонки, проверка, ошибка проверки), настроек.
2. **Настройки**: пороги проверки с пояснением и примером; люди и роли с приглашением и полем «как записан в 1С»
   (для снабжения обязательно); раздел «Подключение 1С»: токены (создание, показ один раз, отзыв),
   обработка выгрузки (скачать модуль, три шага), OData-подключение (форма, «Проверить» с результатом
   «работает / нет доступа / нет документа в публикации», расписание, статус последнего забора), блок MCP
   для ИИ-агентов с готовым конфигом.
3. **Загрузка**: переключатель источника «Файл / Из 1С», плашки «колонки как в прошлый раз» и «колонки предложил ИИ —
   проверьте», выбор строки заголовков, когда шапка не найдена, проверка упала — что делать дальше.
4. **Графики** (сейчас в коде, нужен визуальный дожим и мобильная версия): цена позиции — линии по поставщикам,
   кольца у строк вопроса, отрезок «эталон → цена», полоса рынка по месяцам, перекрестие с подсказкой по всем
   рядам, подписи у концов линий, «весь период / период вопроса»; на телефоне подсказка — нижней панелью по касанию.
   Переплата по месяцам — составные столбцы по правилам. Цвета рядов не меняй без проверки различимости:
   поставщики #9A5B00 (поставщик вопроса), #256abf, #199e70, остальные #8a8f8b; правила P-01 #256abf,
   P-03 #199e70, P-02 #6250d6, P-06 #9A5B00.
5. **ИИ-элементы** без шума: подсказка к ответу снабжения в ключе 1 (видит только собственник: «объясняет /
   частично / не объясняет», что проверить документами, уточняющий вопрос) и панель «Текст для WhatsApp»
   (кто сформулировал: ИИ или шаблон). Никаких «волшебных» значков и градиентов — это подсказка, не решение.
6. **Прототипы трёх потоков**: собственник разбирает вопросы с телефона (решение → следующий → «Отменить»);
   бухгалтер загружает выгрузку (файл → колонки → прогресс → «Отправить собственнику»); снабженец отвечает
   по ссылке из WhatsApp (чипы причин → ответ → следующий).

Ширины 375 и 1280. Тексты — по-русски, без восклицательных знаков. Отдай экраны, состояния и прототипы
в том же файле проекта, отдельным разделом «Проход 2».

## Подробности

### Что исправить из прохода 1

| Где | Проблема | Что нужно |
|---|---|---|
| Карточка вопроса, 1280 px | таблица строк залезала под колонку ключей | раскладка, где таблица из 7 колонок помещается при колонке ключей 320–360 px, или правило переноса |
| График цен | тёмно-зелёный и графитовый поставщики неразличимы | взять проверенные цвета выше |
| Входящие, десктоп | заголовок-вопрос режется в одну строку | две строки или раскрытие по наведению |
| Сводка | нет помесячной динамики | место для графика «Переплата по месяцам» между вопросами и разрезами |

### Состояния, которые нужны на каждом экране

| Экран | Пусто | Загрузка | Ошибка | Особые |
|---|---|---|---|---|
| Сводка | проверок нет (бухгалтер / собственник — разные действия) | скелет героя и списка | сервер не отвечает | идёт новая проверка; переплат не нашли |
| Входящие | всё разобрано; фильтр пуст | скелет строк | — | 200 вопросов; длинные имена |
| Карточка | — | скелет | вопрос не найден или нет доступа | решение принято; ответ дополнен; нет рыночных цен |
| Мои вопросы | вопросов нет | скелет | — | снабженцу не задано имя в 1С — объяснить, кого просить |
| Загрузка | — | читаем файл | не тот формат; больше 25 МБ; шапка не найдена | проверка упала на стадии; 1С не подключена |
| Настройки | токенов и подключений нет | — | ключ шифрования не задан; 1С не отвечает | токен отозван |

### Новые компоненты

- **TokenReveal** — токен показан один раз: моноширинный, «Скопировать», примеры (адрес для обработки, curl, MCP-конфиг).
- **ConnectionCard** — подключение 1С: имя, адрес, расписание, статус последнего забора (ок / ошибка с текстом), действия.
- **SourceTabs** — «Файл / Из 1С» в загрузке.
- **AIHint** — подсказка ИИ: нейтральная, с подписью «подсказка ИИ», без цвета тревоги.
- **ChartTooltip (mobile)** — нижняя панель по касанию с теми же строками, что подсказка на десктопе.

### Критерии приёмки

- [ ] У каждого экрана из таблицы — все четыре состояния.
- [ ] Раздел «Подключение 1С» понятен бухгалтеру без программиста: что выбрать и что передать программисту 1С.
- [ ] Графики читаются на 375 px: подписи не накладываются, подсказка не закрывает данные.
- [ ] Цвета рядов — только из списка выше.
- [ ] ИИ-элементы не выглядят как решение и не используют красный.
