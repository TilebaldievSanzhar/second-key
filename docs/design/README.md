Макет: проект Claude Design «Второй ключ UI mockups», файл «Второй ключ — экраны»
(проход 1 от 15.10.2026: дизайн-система, 5 экранов 375 px, 3 экрана 1280 px).
Реализация — `frontend/src` (токены и компоненты — `styles.css`, экраны — `pages/`).

## Что реализовано по макету

- Токены цвета, шрифты (Golos Text, IBM Plex Mono), радиусы 2/6 px, шаг 4 px.
- KeyPair: контур — ключ не повёрнут, заливка акцентом — ответ, решение — по смыслу,
  штриховка — ошибка учёта; рядом всегда статус словами.
- Вход, сводка, входящие, карточка вопроса с режимом разбора и тостом «Отменить»,
  ответ снабженца с причинами-чипами, новая проверка с сопоставлением колонок.

## Где реализация сознательно отходит от макета

| Место | В макете | В коде | Почему |
|---|---|---|---|
| Цвета поставщиков на графике | тёмно-зелёный, графитовый | янтарь (поставщик вопроса), синий `#256abf`, бирюзовый `#199e70`, остальные — серые «Другие» | у тёмно-зелёного и графитового ΔE < 15 даже при нормальном зрении; новая тройка проходит валидатор (CVD, контраст ≥ 3:1) на поверхности `#FDFDFB` |
| Карточка вопроса, 1280 px | колонка ключей 360 px, таблица строк вылезала под неё | колонка 320 px до 1440 px, таблица с фиксированными колонками, номенклатура обрезается | в макете таблица перекрывала правую колонку |
| Кнопка «Разобрать вопросы» | счётчик «ждут вашего ключа» | счётчик всех ждущих решения | собственник может решать и до ответа снабжения; очередь разбора — все ждущие, крупные сверху |
| Тост на телефоне | снизу | сверху | снизу его закрывала бы панель решений |
| Настройки, состояния, прототипы потоков | следующий проход дизайна | собраны из компонентов системы | макета пока нет |

## Графики (реализованы поверх макета)

- Цена позиции: линии по поставщикам, кольца у строк вопроса, отрезок «эталон → цена», полоса рынка по месяцам
  (медиана ± допуск), перекрестие с подсказкой по всем рядам (мышь, касание, стрелки), подписи у концов линий,
  «весь период / период вопроса».
- Переплата по месяцам на сводке: составные столбцы по правилам (P-01 `#256abf`, P-03 `#199e70`,
  P-02 `#6250d6`, P-06 `#9A5B00` — соседние пары проходят валидатор), подпись только у максимума,
  скрытая таблица для скринридеров.
