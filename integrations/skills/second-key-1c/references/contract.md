# Контракт строк закупок

`POST {адрес}/api/integrations/purchases` с `Authorization: Bearer sk_…` (право `push`) или MCP-инструмент
`submit_purchases` — один и тот же формат. Источник истины — `backend/src/secondkey/integrations/contract.py`.

```json
{
  "source": "1c:bp30",
  "period_start": "2025-10-01",
  "period_end": "2026-09-30",
  "lines": [
    {
      "date": "2026-01-17",
      "doc": "Поступление товаров и услуг 0002388 от 17.01.2026",
      "supplier": "ИП Сыдыков А.Т.",
      "supplier_inn": "20909197900124",
      "item": "Арматура А500С ф14",
      "unit": "т",
      "qty": "4.246",
      "price": "82538.19",
      "amount": "350457.15",
      "vat": "37549.08",
      "object": "ЖК «Ордо», Бишкек",
      "responsible": "Асанов Б.",
      "ref": "GUID документа",
      "doc_in_no": "СФ-000417",
      "doc_in_date": "2026-01-16"
    }
  ],
  "suppliers": [
    {
      "name": "ИП Сыдыков А.Т.",
      "inn": "20909197900124",
      "phone": "+996 555 41-27-09",
      "address": "г. Бишкек, ул. Складская, 12",
      "email": "sydykov@example.kg",
      "bank_account": "1180000123456789"
    }
  ],
  "staff": [
    {"name": "Бекова С.", "role": "прораб", "inn_hash": "sha256 от «соль:ИНН», 64 hex-символа"}
  ]
}
```

| Поле | Обязательно | Что |
|---|---|---|
| date | да | дата документа, ГГГГ-ММ-ДД |
| supplier | да | наименование контрагента |
| item | да | номенклатура как в 1С, без правок |
| qty | да | количество в единице документа, > 0 |
| price / amount | хотя бы одно | цена за единицу; сумма строки с НДС |
| doc, supplier_inn, unit, vat, object, responsible, ref | нет | улучшают доказательства и разрезы |
| doc_in_no, doc_in_date | нет | входящие номер и дата документа поставщика: «номера подряд» — признак, что вы его почти единственный клиент |

`suppliers` (необязательно) — реквизиты контрагентов из их карточек: `name` как в строках, `inn`, `phone`,
`email`, `address`, `bank_account` (основной счёт). По ним видны «конкуренты» с одним владельцем.

`payments` (необязательно) — оплаты поставщикам за тот же период: списания с расчётного счёта и расходные
кассовые ордера с видом «оплата поставщику». Поля: `date`, `supplier` и `supplier_inn` (как в строках), `amount`
(с НДС), `doc`, `purpose` (назначение платежа). По ним видны авансы без поставки, предоплата и оплата вне очереди.

`staff` (необязательно, по решению клиента) — сотрудники и пользователи 1С: `name` как в поле «Ответственный»,
`role`, `inn_hash` = SHA-256 (hex, нижний регистр) от строки `соль:ИНН`. Соль организации — поле `inn_salt`
ответа `GET {адрес}/api/integrations/ping`. Сами ИНН сотрудников не передаются; совпадение хэша с ИНН
поставщика — вопрос «поставщик — ваш сотрудник?». Через MCP `staff` не принимается — только обработкой 1С.

Числа — числом или строкой, дробная часть через точку.
Ответ: `202 {"run_id": "…", "status": "queued", "lines": N, "status_url": "…/api/audits/{run_id}"}`.
Ошибка формата — `422` со списком полей.
